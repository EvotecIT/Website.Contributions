Exporting a few paragraphs to Word is easy. Creating a document that someone can actually review, navigate, approve, and keep as evidence takes a little more structure.

This example builds an executive service-health report from PowerShell objects. It includes a generated banner, headers and footers, a table of contents, a conditionally highlighted service table, a chart, an action table, a bookmark link, approval controls, document properties, one footnote, and one endnote.

![Generated executive report banner](./images/executive-report-banner.png)

## The Shape

The full script lives in `Examples/Showcase/Showcase-Word-ExecutiveReport.ps1`. The interesting part is that the document is composed from ordinary PowerShell data:

```powershell
New-OfficeWord -Path $path {
    WordSection {
        WordHeader {
            WordParagraph {
                WordBold 'PSWriteOffice Showcase'
                WordText ' | Executive service health'
            }
        }

        WordParagraph -Text 'Executive Service Health Report' -Style Heading1
        WordImage -Path $heroPath -Width 640 -Height 147
        WordTableOfContent -Style Template1

        WordParagraph -Text 'Service Scorecard' -Style Heading1
        WordTable -InputObject $services -Style GridTable4Accent1 -Layout AutoFitToWindow {
            WordTableCondition -FilterScript { $_.Status -eq 'Needs action' } -BackgroundColor '#fde2e2'
            WordTableCondition -FilterScript { $_.Status -eq 'Watch' } -BackgroundColor '#fff4cc'
        }
    }
}
```

## Why It Matters

The document is not just a rendered blob. It stays editable in Word, keeps metadata, exposes approval controls, and carries notes for reviewers:

```powershell
WordParagraph {
    WordText 'Rows needing attention are highlighted so the table remains useful after export.'
    WordEndnote 'Risk labels combine current incident count, owner feedback, and observed availability trend.'
}
```

The generated file can also be inspected after creation:

```powershell
$document = Get-OfficeWord -Path $path -ReadOnly
@{
    Tables    = $document.Tables.Count
    Charts    = $document.Charts.Count
    Footnotes = @(Get-OfficeWordFootnote -Document $document).Count
    Endnotes  = @(Get-OfficeWordEndnote -Document $document).Count
}
```

## Wrap-Up

This is the kind of Word output that works as a report, not just an export. `OfficeIMO` handles the Open XML document engine, while `PSWriteOffice` makes the authoring flow feel natural from PowerShell.
